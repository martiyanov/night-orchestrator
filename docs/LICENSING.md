# Лицензирование

**Выбор владельца: Apache License 2.0.** Официальный текст — в корне репозитория (`LICENSE`), неизменён.

Почему Apache-2.0 (из рассмотренных вариантов):
- короткая и понятная, как MIT, но с явной патентной грантью — осмысленно
  для инструмента вокруг LLM-провайдеров;
- коммерческое использование и закрытые производные разрешены;
- требует сохранения NOTICE/уведомлений — честно для продукта,
  выросшего из рабочей установки.

Сравнение с альтернативами (MIT: нет патентной гранти; GPL-3.0: copyleft,
закрытые производные невозможны) — оставлено для истории ниже.

(история выбора)

| | MIT | Apache-2.0 | GPL-3.0 |
|---|---|---|---|
| Суть | максимум свободы использования | MIT + патентная гранть | copyleft |
| Патентная защита | нет | явная | есть |
| Коммерческое использование | да | да | да (с условиями) |
| Производные могут быть закрытыми | да | да | нет |
| Простота | максимально | средняя (NOTICE) | сложнее |

Рекомендация: **Apache-2.0** — короткая и понятная, как MIT, но с явной
патентной грантью, что осмысленно для инструмента вокруг LLM-провайдеров.
Если цель — гарантировать открытость производных оркестраторов, GPL-3.0.

Решение принято 2026-09-27: Apache-2.0, файл LICENSE в корне.
