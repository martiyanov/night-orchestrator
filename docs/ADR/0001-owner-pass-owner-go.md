# OWNER PASS и OWNER GO разделены

Контекст: принятие кода и развёртывание — риски разной природы; автопринятие ведёт к каскадным ошибкам.
Решение: два явных разрешения владельца: PASS (код принят к слиянию) и GO (production-деплой). Автоматического обхода нет ни в одном слое.
Последствия: человек в контуре на каждом повышении риска; оркестратор не может сам изменить мир.
