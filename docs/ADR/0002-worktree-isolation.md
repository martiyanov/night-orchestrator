# Каждая задача — отдельный worktree

Контекст: исполнение в основном чекауте однажды привело к потере данных рабочей копии.
Решение: writable-задачи выполняются в одноразовом git worktree со своей веткой; основной чекаут неприкосновенен.
Последствия: откат исполнения тривиален; расходы на создание worktree пренебрежимы.
