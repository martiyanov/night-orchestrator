# Распознавание проекта — вне ядра

Контекст: ассистент обслуживает много проектов; глобальный перехватчик сообщений неприемлем.
Решение: ядро универсально; принадлежность сообщения определяет проектный навык (wake-word); Intake проектно-нейтрален и вызывается навыком.
Последствия: новые проекты добавляются навыком по шаблону без изменений ядра.
