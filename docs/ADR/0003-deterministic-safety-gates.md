# Безопасность — кодом, не промптами

Контекст: промптовые запреты обходимы уговором модели.
Решение: детерминированные shell-гейты (классы команд, jail, forbidden/guard-пути, пост-аудит диффа); системный промпт — только вторичная линия.
Последствия: гейти требуют сопровождения (уроки реальных прогонов — см. SAFETY_MODEL.md), но не поддаются социальной инженерии.
