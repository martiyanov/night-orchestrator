# Модели по ролям, не по вендору

Контекст: жёсткая привязка к одному провайдеру дорожит и не масштабируется.
Решение: роли explorer/implementer/strong_finalizer/reviewer в конфиге; любой провайдер; событийная эскалация и reasoning-budget ladder.
Последствия: дешёвый обычный путь, дорогой — только по событию; смена вендора — правка конфига.
